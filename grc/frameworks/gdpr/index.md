# GDPR: the php2shell risks it governs

A PHP application that executes an attacker's code exposes the personal data it holds; whoever controls that data answers for its security and for notifying a breach.

**Full name** General Data Protection Regulation, Regulation (EU) 2016/679 · **Publisher** European Union · **Version** 2016, in force 25 May 2018 · [the official text](https://eur-lex.europa.eu/eli/reg/2016/679/oj)
