Quiet hours

22:00 to 07:00 Europe/London. Nothing scheduled runs between 22:00 and 07:00 London time. A run that would fall in those hours is moved to 07:00 or skipped. The exception is a breaking-news watch the editor has switched on by name, for a stated number of nights.

Every run with changes leaves an article

A run that changes something a reader can see (a grade, a series, a new capture, a review with failures) leaves a dated article in admin/content/articles/ whose front matter names the run (run: <run id>). A run that changes nothing leaves one line in its own log and no article. The runs page flags every run with changes and no article.

PHP October 2026 (php.oct.2026.newsroom.sgit.ai) tracks PHP news for one month. This month that is one story, the two critical PHP security flaws, followed as evidence: every claim with a status and its sources, every source captured, dated and hashed into a private vault. Built and run by one editor and a team of software agents; the roles and the method are public, and the site is rebuilt from the vault, never written by hand. One of the SGit Newsroom's story sites: up from here are October 2026, the year and the newsroom, whose own section on the story is here. Part of the sgit.ai network.
