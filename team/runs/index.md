## Quiet hours

**22:00 to 07:00 Europe/London.** Nothing scheduled runs between 22:00 and 07:00 London time. A run that would fall in those hours is moved to 07:00 or skipped. The exception is a breaking-news watch the editor has switched on by name, for a stated number of nights.

## Every run with changes leaves an article

A run that changes something a reader can see (a grade, a series, a new capture, a review with failures) leaves a dated article in admin/content/articles/ whose front matter names the run (run: ). A run that changes nothing leaves one line in its own log and no article. The runs page flags every run with changes and no article.
