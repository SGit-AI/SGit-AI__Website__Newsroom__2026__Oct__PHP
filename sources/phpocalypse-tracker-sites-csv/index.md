#### What the page says

_Curator's reading of the capture._

The PHPocalypse Tracker's (allixsenos, GitHub Pages) machine-readable list of sites that went dark over php2shell: a CSV with columns name, url, country, type, dark_since, back_up, source, notes. At this snapshot (18:36 UTC) it has 50 rows: 48 with a back_up time and 2 still dark; 24 are in the Netherlands. Each row cites a source (often a post on X) and notes how it was checked (e.g. manual browser checks, HTTP status). It is a community dataset, not an official list: each row's claim is only as good as the source it cites. The watch fetched it over HTTP, so there is no rendered.html and no screenshot.
