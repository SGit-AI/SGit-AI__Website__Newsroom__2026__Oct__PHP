#### What the page says

_Curator's reading of the capture._

NÚKIB, the Czech National Cyber and Information Security Agency, warns of two critical PHP vulnerabilities known as php2shell, CVE-2026-109618 and CVE-2026-109619, which could allow unauthenticated remote code execution. Fixes have been released in PHP 8.2.35, 8.3.36, 8.4.27 and 8.5.12 and NÚKIB recommends updating immediately ("the only solution is to update"); it says information enabling exploitation is publicly available. As a possible indicator of compromise it names unusual processes spawned by PHP services. It links to a detailed notice on the NÚKIB portal.

> Pro dvě kritické zranitelnosti označované jako php2shell už byly zveřejněny bezpečnostní opravy a veřejně jsou dostupné také informace umožňující jejich zneužití.

_Curator's translation:_ Security fixes have already been published for the two critical vulnerabilities known as php2shell, and information enabling their exploitation is also publicly available.

> Opravené verze jsou PHP 8.2.35, 8.3.36, 8.4.27 a 8.5.12. Doporučení je aktualizovat okamžitě.

_Curator's translation:_ The fixed versions are PHP 8.2.35, 8.3.36, 8.4.27 and 8.5.12. The recommendation is to update immediately.
