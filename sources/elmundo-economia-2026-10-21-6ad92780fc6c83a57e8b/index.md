_Curator's reading of the capture._

El Mundo (Spanish), 21 October: PHP2Shell is the name the security community gave to two critical PHP flaws in the language behind about 70% of websites. The project published the fixed versions on Wednesday with an unusual message: no setting can fully protect, only the update does. It explains CVE-2026-109618 as arising when PHP runs out of memory mid-request and leaves internal structures half built, which the clean-up phase then treats as complete.
