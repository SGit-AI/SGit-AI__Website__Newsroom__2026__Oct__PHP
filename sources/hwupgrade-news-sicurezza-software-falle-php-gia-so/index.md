#### What the page says

_Curator's reading of the capture._

Hardware Upgrade (Italian): PHP flaws already under attack, AI found them and now writes the exploits. The PHP security team released PHP 8.5.12, 8.4.27, 8.3.36 and 8.2.35 the previous day to fix CVE-2026-109618 (GHSA-w8hw-w9fx-j79w, from out-of-memory handling) and CVE-2026-109619 (GHSA-6wmf-4rv5-p3rp, stale global state), both 9.2 and able to allow unauthenticated remote code execution. It adds that OpenAI says the researchers found the flaws before attackers and that the weaknesses already existed, while admitting AI 'can also help attackers exploit them', and quotes Wiz that the complexity of exploiting them is no longer an obstacle with AI, since LLMs can help adapt an exploit to different PHP versions, configurations and memory layouts.

> Nel corso della giornata di ieri il team di sicurezza di PHP ha rilasciato PHP 8.5.12, 8.4.27, 8.3.36 e 8.2.35 per correggere due vulnerabilità critiche, CVE-2026-109618 e CVE-2026-109619, che possono consentire l'esecuzione di codice da remoto senza autenticazione.

_The watch reader's summary (researcher@php.newsroom, of its snapshot 20261022T181608Z, not necessarily this one):_ Hardware Upgrade covers the patch releases, the mitigations and the AI discovery story (Calif reported on 11 August and Wiz on 24 August, per Futurism). Citing The Record, it says hundreds of sites were unreachable and that Nintendo suspended services.
