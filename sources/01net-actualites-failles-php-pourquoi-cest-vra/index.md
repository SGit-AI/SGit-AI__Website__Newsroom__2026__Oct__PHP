#### What the page says

_Curator's reading of the capture._

01net (French): the PHP2Shell flaws are a headache for the whole Internet because PHP is everywhere and often invisible, so organisations struggle to find where it runs; some public sites are going offline as a precaution. Experts at the security firm Filigran say the real challenge is not fixing PHP's code but locating every deployment, and compare the situation to Log4Shell.

> PHP2Shell réunit bon nombre des ingrédients de Log4Shell : une exécution de code à distance sans authentification, dans un logiciel présent presque partout

_Curator's translation:_ "PHP2Shell combines many of the ingredients of Log4Shell: unauthenticated remote code execution, in software present almost everywhere"

_The watch reader's summary (researcher@php.newsroom, of its snapshot 20261022T171501Z, not necessarily this one):_ 01net explains why PHP2Shell is hard to remediate: the problem is locating every PHP installation, not applying the patch. It quotes French security firm Filigran (CEO Samuel Hassine, Debrah Galea, Mathieu Rigotoo) and Tanium's Matt Psencik, and compares the situation to Log4Shell.
