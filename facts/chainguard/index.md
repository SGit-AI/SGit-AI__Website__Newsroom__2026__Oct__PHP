# Chainguard unilaterally broke the embargo on 21 October at 07:41 UTC by publishing built images containing the fix

**Who says it:** PHP Foundation; Chainguard's CEO accepts the time and denies leaking · **Sources:** [PHP Foundation](../../sources/php-foundation-blog-security-release/index.html) [The Register](../../sources/theregister-php-blames-chainguard/index.html) [Feross Aboukhadijeh on X on X](../../sources/x-feross-chainguard/index.html)
