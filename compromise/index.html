It makes no assessment of risk. The statement's status is reported: A time-bounded absence, not a confirmed fact. It is true only as of the last check, and one statement from one organisation would end it. It is claim no-confirmed-compromise.

What would change the statement

  • A named organisation saying it was compromised through php2shell, in its own notice, filing or statement.
  • GMO, ČVUT or DMM stating a cause.
  • A KEV listing for either CVE, with CISA's evidence.
  • A regulator's breach notice (for example under GDPR or Australia's Notifiable Data Breaches scheme) naming the flaw.
  • A security vendor naming a victim, with the victim's consent.

The source watch checks the official lists and the named organisations' pages every 30 minutes; this page is rebuilt from data/compromise.json when the evidence changes.

How this page is made

Every row is in data/compromise.json. Rows with sources cite captures in the evidence vault, which the build checks. Rows marked source watch cite a dated snapshot folder in the source-watch vault (oq9gflln), read with its published key; they move into the evidence vault as the evidence curator promotes them. Statements read in another language carry the reader’s English translation beside the verbatim original in the watch’s translations/ files. The charts are drawn from the same rows when the site is built.
